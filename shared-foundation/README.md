# Shared incident foundation

This small standard-library Python project records a support incident as separate evidence:

1. Observable symptom
2. Plausible cause
3. Confirming test
4. Verification procedure
5. Verification result

Run the example from this directory:

```text
python3 incident_record.py
```

Expected output:

```text
ready for confirmation
```

Run the tests with:

```text
python3 -m unittest discover
```
